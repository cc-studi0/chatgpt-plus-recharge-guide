## 一句话结论

- **有自己名下、能正常付外币的信用卡**：直接在 chatgpt.com 官网订阅，链路最短，售后找 OpenAI。
- **有能正常付款的海外 Apple ID**：在 iPhone 的 ChatGPT App 里内购，订阅归 Apple 管，退款也找 Apple。
- **两样都没有，只有微信 / 支付宝**：选第三方充值（代充）平台，但要用下面的 [12 项清单](#代充--充值平台怎么判断靠不靠谱12-项检查清单) 先筛一遍。
- **共享账号 / 拼车**：最便宜，但 OpenAI 明确禁止共享账号凭据，隐私也无法保证，不建议用于正式工作。
- **只想用 Codex 写代码**：Codex 不单独卖，包含在 ChatGPT 的 Go / Plus / Pro 里。先从 Plus 开始，用量不够再考虑 Pro 或额外购买 credits。详见 [Codex 专题](docs/codex.md)。

## Plus、Pro、Go 和 Codex 有什么区别，谁该买哪个

下面的功能差异来自 [ChatGPT 官方定价页](https://chatgpt.com/pricing/)（2026-10-20），只挑和选档有关的几项：

| 对比项 | Go | Plus | Pro（100 / 200 / 500） |
|---|---|---|---|
| 定位（官方原话意译） | 更长的对话 | 进阶工作和效率 | 研究和编程 |
| 推理模型 GPT-6 Astra | 无 | 有 | 有，并提供 Pro 推理 |
| Codex | 有限 | 有 | 扩展额度 |
| 深度研究 | 有限 | 有 | 最高额度 |
| GPT Instant 上下文窗口 | 54K | 54K | 128K |
| 推理模型上下文窗口 | 256K | 256K | 400K |
| 广告 | 定价页注明“可能包含广告” | 未注明 | 未注明 |

**怎么选（经验建议，不是官方结论）**：

1. **一周只用几次、主要是聊天和查资料** → Go。先用最低成本确认自己是不是真的会长期用。
2. **每天都用，写作、办公、学习、偶尔写代码** → Plus。绝大多数个人用户的合理起点。
3. **Plus 的额度确实反复卡住工作**（不是偶尔报错一次）→ 先看能不能买 credits 补用量，再考虑 Pro 100。
4. **长时间跑 Codex 或深度研究、整天离不开** → Pro 200 或 Pro 500。Pro 500 多出的主要是 Ultrafast 模式和更高的额度，没有这个刚需就没必要直接上顶档。

> 判断要不要升档，最可靠的办法是记一周：有没有因为额度用完而中断了真正要交付的任务。单次请求失败、页面加载慢、网络问题都不算。

## 每种方式具体怎么操作

### 方式一：官网直接订阅

1. 用浏览器登录 [chatgpt.com](https://chatgpt.com/)，点头像 → **Upgrade plan（升级套餐）**。
2. 选 Go / Plus / Pro，填写卡号和账单地址。
3. 付款成功后，到 **设置 → 账户** 查看当前方案和下次续费日期。

**卡点**：国内银行发的卡经常被拒付。另外，OpenAI 的 [支持地区列表](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries) 里没有中国大陆和中国香港，官方写明在不支持的地区访问“可能导致账号被封禁或停用”。

### 方式二：iOS App 内购

1. 准备一个能下载 ChatGPT 的地区的 Apple ID（2026-10-20 实测：中国大陆区、香港区的 App Store 商品页都是 404，美区、新加坡区、日本区、台湾区都能打开）。
2. 在 App 里点升级，用 Apple ID 的余额或绑定的付款方式付款。
3. 订阅之后由 Apple 管理：在 iPhone **设置 → Apple ID → 订阅** 里取消；如果 App 里显示还是免费版，可以在 App 设置里点 **Restore purchases（恢复购买）**。

**卡点**：外区 Apple ID 怎么充值余额。这一步通常就是买礼品卡，看方式三。

### 方式三：礼品卡

- **Apple 礼品卡**：买对应地区的礼品卡，兑换到外区 Apple ID，再走方式二。风险在卡源：低价卡可能是盗刷来的“黑卡”，兑换后 Apple ID 可能被锁。只从可信的渠道买，价格明显低于面值的不要碰。
- **OpenAI 自家礼品卡**：官方 [多币种计费说明](https://help.openai.com/en/articles/10421635-multicurrency-billing) 写明，礼品卡目前只在美国购买和兑换，以美元计价，兑换后进入 ChatGPT 钱包余额，只能用于符合条件的美元结算。国内用户基本用不上。

### 方式四：第三方充值 / 代充平台

主流平台的流程大同小异：

1. 在平台选择方案（Plus / Pro / Go），用微信或支付宝付款。
2. 按平台要求提供交付所需的信息。常见有两种：
   - **卡密 / 兑换链接**：平台给你一串卡密，你自己去指定页面兑换；
   - **会话凭据（Session）**：你登录自己的 ChatGPT 后，从平台指定的入口复制 Session 粘贴到平台的订单页，由平台为你的账号开通。
3. 平台处理完成后，你**自己登录 ChatGPT，到设置里核对方案名称和到期日**，这才算真正到账。

以 Plus宇宙 为例（[图文教程](https://www.pluscosmo.com/guide)）：用的是第二种 Session 方式，不要密码和验证码；支持微信、支付宝；在售套餐写有 30 天订阅质保，失效优先补开，补不了按剩余天数退款，账号被封不在质保范围内。处理时效、凭据怎么清理、客服时间写在它的 [信任中心](https://www.pluscosmo.com/trust)。

> **关于 Session 的提醒**：Session 虽然不是密码，但它**可能等同于一段时间内的登录权限**，所以只能填在平台自己的 HTTPS 订单页里，不要发到群聊、私聊或截图里。开通完成后，可以在 ChatGPT 的 **设置 → 数据控制** 里退出所有设备，让这份 Session 立即失效。

### 方式五：共享账号 / 拼车 / 成品号（不推荐）

- OpenAI 在 [Pro 帮助页](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers) 写明：**共享账号凭据、转售访问权限、自动抓取数据都被禁止**，可能因此被限制访问。
- 共享账号里的对话记录、上传的文件，同车的人都可能看到。
- 成品号（直接买一个别人注册好的账号）不归你所有，原主或卖家随时可能改密码或把号找回。
- 如果只是想“先体验一下”，免费版或者 Go 通常比共享账号更安全，也不贵。

## 代充 / 充值平台怎么判断靠不靠谱：12 项检查清单

付款前逐项核对，有 3 项以上做不到就换一家：

**凭据安全**
1. ☐ 不要 ChatGPT 密码、邮箱密码、短信或邮箱验证码、双重验证恢复码。
2. ☐ 提交凭据的入口是平台自己的 HTTPS 页面，而不是让你发给客服微信或填到第三方表单。
3. ☐ 写明凭据用完后怎么处理（比如订单完成后清空），以及你自己怎么让它失效。

**价格和交付**
4. ☐ 价格明码标出，并写清周期（1 个月？按官方账期？）。
5. ☐ 写清交付的是什么：给你自己的账号开会员，还是给你一个新账号。
6. ☐ 写清已有订阅的账号怎么处理，不默认“会自动叠加”。
7. ☐ 不承诺“锁定旧额度”“永久可用”“绝不封号”这类官方都做不到的事。

**订单和售后**
8. ☐ 有订单号和订单状态页，付款后能查进度。
9. ☐ 有明确的质保或退款规则，写清哪些情况**不**包括（比如账号被封）。
10. ☐ 公开了客服时间和至少一种可以反向核实的联系方式。
11. ☐ 只在平台生成的订单里付款，不要求私下转账到个人账户。

**到账验收**
12. ☐ 平台自己也要求你登录官方账号核对方案和到期日，而不是拿“能聊天了”当作到账。

> 能开发票、页面做得漂亮、价格低，都不能单独证明一家平台靠谱。真正有用的信号是：凭据要求最小、规则写在页面上、出了问题能按订单号找到人。

## Codex 订阅、充值和价格

**先说结论：没有单独的“Codex 会员”**。Codex 包含在 ChatGPT 方案里，所以“Codex 充值”“Codex 订阅”本质上就是给 ChatGPT 账号开 Go / Plus / Pro，或者额度用完后再买 credits。

| 方案 | 官方月费 | Codex 能用到什么（摘自 [Codex 定价页](https://learn.chatgpt.com/docs/pricing)） |
|---|---|---|
| Free | $0 | 桌面 App 里用 GPT-6 Luna 做简单任务（逐步开放） |
| Go | $8 | 同 Free，适合很轻量的编程任务 |
| Plus | $20 | 网页、CLI、IDE 插件、iOS 都能用；自动代码审查、Slack 集成；可以买 credits 扩展用量 |
| Pro | $100 / $200 / $500 | 在 Plus 基础上额度更高；Pro 500 有 Ultrafast 模式 |
| API Key | 按 API 价格 | 适合 CI 等自动化场景；不支持云端功能（GitHub 代码审查、Slack 等） |

三种常被混为一谈的“Codex 充值”：

1. **开会员**：给 ChatGPT 账号开 Plus / Pro，Codex 额度随会员走。
2. **买 credits**：会员额度用完后，在 ChatGPT 的 **设置 → 用量** 或 Codex 的 **Usage & Billing** 里买，先扣会员自带额度，再扣 credits（[官方说明](https://help.openai.com/en/articles/12642688-using-credits-for-flexible-usage-in-chatgpt-personal-plans)）。美区 App Store 的价格是 100 credits = $4。
3. **API 余额**：在 OpenAI 开发者平台按 API 价格计费，跟 ChatGPT 会员是两套账。

Plus 每 5 小时大概能发多少条本地消息、Pro 有没有 5 小时限制、Fast / Ultrafast 模式消耗额度的倍率、怎么让额度更耐用，单独写在 👉 **[docs/codex.md](docs/codex.md)**。想看 Codex 各档的人民币成本怎么算，可以参考 Plus宇宙 的 [Codex 价格与套餐选择](https://www.pluscosmo.com/blog/codex-pricing-subscription-guide)。

## 常见问题 FAQ

<details>
<summary><b>1. 国内没有海外信用卡，能开 ChatGPT Plus 吗？</b></summary>

能。常见的是外区 Apple ID + 礼品卡（方式二、三），或者用微信、支付宝在第三方平台充值（方式四）。官网目前不能直接用微信、支付宝付款；官方列出的本地支付方式只有印度 UPI、印尼 GoPay、巴西 Pix、韩国 Kakao Pay / Naver Pay、菲律宾 GCash 等（[来源](https://help.openai.com/en/articles/10421635-multicurrency-billing)）。
</details>

<details>
<summary><b>2. 代充和充值有什么区别？</b></summary>

在中文搜索里基本是一回事，指的都是通过第三方用人民币帮你的账号开会员。要区分的是**交付方式**：是给你**自己的账号**开通（卡密或 Session），还是直接卖你一个账号（成品号或共享号）。前者账号是你的，后者不是。
</details>

<details>
<summary><b>3. 代充会不会被封号？</b></summary>

没有人能保证不封。官方明确禁止的是共享账号凭据、转售访问权限、在不支持的地区使用；用的是黑卡或盗刷来的余额，订阅也可能被撤销。所以要选给你自己账号开通、来源说得清的渠道，同时注意自己的使用环境。凡是承诺“绝不封号”的，反而要警惕。
</details>

<details>
<summary><b>4. 充值需要把 ChatGPT 密码给对方吗？</b></summary>

不需要，任何渠道都不需要。正规平台最多要卡密兑换或一段 Session，密码、验证码、恢复码一律不该交出去。
</details>

<details>
<summary><b>5. 已经是 Plus，还能再充一个月吗？会叠加吗？</b></summary>

官方不支持预付多个月。已经有订阅时，先查清原订阅是从哪里付的（官网 / Apple / 第三方）、什么时候到期、有没有开自动续费，再问清楚平台怎么衔接。不要默认会叠加，否则可能出现两处同时扣费。
</details>

<details>
<summary><b>6. 付完钱怎么确认真的到账了？</b></summary>

登录**同一个** ChatGPT 账号，到 **设置 → 账户** 看方案名称和到期日。“能聊天”“能看到某个模型”都不能证明到账。如果显示还是免费版，先确认登录的是不是同一个账号（尤其用 Apple“隐藏邮箱”登录的），App 端可以点“恢复购买”。
</details>

<details>
<summary><b>7. Plus 包含 API 额度吗？</b></summary>

不包含。会员和 API 是两套独立的账单，开会员不会给 API 账户加钱（[官方说明](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)）。
</details>

<details>
<summary><b>8. Pro 100、Pro 200、Pro 500 怎么选？</b></summary>

额度从低到高依次是 100、200、500，只有 Pro 500 有 Ultrafast。Plus 偶尔不够用，先考虑买 credits；长期每天都触限，再上 Pro 100；整天跑 Codex 或深度研究再看 200 / 500。官方没有公布各档的精确倍数，以账号里的用量页面为准。
</details>

<details>
<summary><b>9. Go 和 Plus 差在哪？Go 会有广告吗？</b></summary>

Go 是 $8 的轻量档：消息、上传、图像生成都比 Free 多，但没有 GPT-6 Astra 等推理模型，Codex 和深度研究也只有有限额度。官方定价页写明 Go “可能包含广告”。
</details>

<details>
<summary><b>10. 想退订或退款找谁？</b></summary>

找你付款的那一方：官网订阅找 OpenAI，App Store 订阅找 Apple，第三方平台按它的质保规则处理。取消只是停止下次续费，一般能用到本期结束；取消不会自动退钱。
</details>

<details>
<summary><b>11. 只用 Codex 写代码，需要单独买 Codex 吗？</b></summary>

不需要，也买不到单独的 Codex 会员。Codex 跟着 ChatGPT 方案走，Plus 起就能在 CLI、IDE 插件和网页里用。详见 [docs/codex.md](docs/codex.md)。
</details>

<details>
<summary><b>12. 平台显示的价格和官方差这么多，钱差在哪？</b></summary>

官方是外币标价，平台是人民币标价，中间有汇率、换汇或礼品卡成本、平台的人工和售后成本。比价时把周期、交付方式、质保范围放在一起看，只比数字容易买错。
</details>
