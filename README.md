## 一、先说我的结论

我最后留下来的是：**自有账号 + Plus + 钱包里常备一点余额**。理由很朴素 —— 账号是我的，聊天记录、项目、自定义 GPT 都在上面，换号成本比省下的那点钱高得多。

如果你只想拿一句话走：

- **有能用的外币卡，且使用环境符合官方要求** → 走官网，最短路径，别绕。
- **iPhone + 有可付款的外区 Apple ID** → App 内购，能付款就一直用。
- **只有微信 / 支付宝** → 走代充，但**先把平台筛一遍再付钱**，筛的标准在第九节。
- **只想临时体验** → 用 Free 或 Go，别买别人的成品号，理由见第二节。

## 二、先分清：你充的到底是什么

「ChatGPT 充值」充的是 **ChatGPT 付费订阅（Go / Plus / Pro）**，开在**你自己的**账号上。账号有了对应档位，才有对应的用量和功能。

它**不是**下面三样东西里的任何一个：

- **OpenAI API 平台余额**：开发者按用量计费，和会员是两套账单（来源：[Managing billing for ChatGPT and the API platform](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)）；
- **别人注册好的成品号，或多人共用的拼车号**：账号不归你，对话也可能被别人看到；
- **单独的「Codex 会员」**：Codex 用量跟着 ChatGPT 方案走，Free 和 Go 也能用，只是功能和用量有限（来源：[Using Codex with your ChatGPT plan](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)）。

对号入座表：

| 你的情况 | 实际要办的事 | 正确入口 |
| --- | --- | --- |
| 想用付费能力，账号还是 Free | 开通 Go / Plus / Pro 订阅 | 第三节的三条路径 |
| 已是 Plus / Pro，只是某段时间不够用 | 官方补充用量（credits），或评估升档 | 账号内「设置 → 用量」 |
| 用 API Key 调用模型或做自动化 | API 平台余额 | [OpenAI 开发者平台](https://platform.openai.com/) |
| 其实只想把 Codex 用起来 | 仍是给 ChatGPT 开会员（或买 credits） | 另见 [Codex 充值指南](https://github.com/cc-studi0/codex-daichong) |

我在这一步浪费过时间：一开始以为「充值」是往一个余额里打钱，后来才明白买的是**一个档位 + 一个账期**。理解错这层，后面所有的坑都会踩一遍。

## 三、三条路径，我都走过一遍

国内能实际走通的就是这三条。共享账号、拼车、成品号我单独列出来，因为「不可控」这三个字在这里代价最大。

| 路径 | 能否微信 / 支付宝 | 账号归属 | 我的实际结果 |
| --- | --- | --- | --- |
| 官网直接订阅（chatgpt.com） | 否，通常需要国际卡 + 受支持地区 | 自己的账号 | 试了两次被拒付，放弃 |
| App Store 内购 / 礼品卡 | 视 Apple ID 区服与余额来源而定 | 自己的账号 | 能付，但每次续费要切区 |
| 代充（第三方为自有账号开通） | 是，多数支持人民币 | 自己的账号（正规交付） | 最后留下当常规方式 |

> 表里的差别只落在「付款和账号归属」这一环。会员的功能与用量由**账号的官方档位**决定，跟你从哪条路付款无关 —— 别被「某渠道的会员额度更高」这类说法骗。

**为什么我不推荐共享账号 / 拼车 / 成品号**

- 账号往往**不归你**，卖家随时能改密码、收回，或者看到你的对话；
- OpenAI 使用条款写明不得共享账号凭据或让第三方使用账号，Pro 说明页也把共享凭据、转售访问权限列为禁止行为，可能导致访问被限制（来源：[Terms of Use](https://openai.com/policies/terms-of-use)、[About ChatGPT Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)）；
- 你上传的文件、对话记录，同车的人都可能看到。工作用途基本不用考虑。

**官网路径我卡在哪**

1. 登录 [chatgpt.com](https://chatgpt.com/)，点头像 → Upgrade plan，选档后填卡和账单地址。
2. 我是国内发卡，两次都被拒。官方[支持地区列表](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)不含中国大陆与中国香港，官方写明在列表以外的地区访问可能导致账号被封禁或停用。
3. 付款成功后，认 **设置 → 账户** 里的方案名，不要只看「能聊天了」。

**App Store 路径我卡在哪**

1. 需要能下载官方 ChatGPT App 的区服 Apple ID，部分区服的商店页长期不可用。
2. 外区余额多靠礼品卡：只从可信渠道买，价格明显低于面值的别碰。
3. 订阅由 Apple 管：取消在 iPhone **设置 → 你的名字 → 订阅**；退款也找 Apple。卸载 App 不会自动取消订阅（来源：[Canceling your ChatGPT subscription](https://help.openai.com/en/articles/7232927-canceling-your-chatgpt-subscription)）。

## 四、官方美元档位速查

| 档位 | 官方月费 | 我什么时候会选它 |
| --- | --- | --- |
| Go | $8（美国标价；部分地区为本地化定价） | 轻量使用；不含 Codex Cloud |
| Plus | $20 | **多数个人用户的日常主力，也是我一直在用的** |
| Pro 100 | $100 | Plus 的用量反复卡住交付，先试这一档 |
| Pro 200 | $200 | 用量多于 Pro 100；2026-10 官方已撤销此前公告的用量下调 |
| Pro 500 | $500 | 三档中用量最高；唯一包含 Ultrafast 的个人方案 |

来源：[What is ChatGPT Plus?](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)、[About ChatGPT Pro tiers](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-tiers)、[Introducing ChatGPT Go](https://openai.com/index/introducing-chatgpt-go/)、[What is ChatGPT Go?](https://help.openai.com/en/articles/11989085-what-is-chatgpt-go)、[Codex Pricing](https://learn.chatgpt.com/docs/pricing)。

几个容易忽略的官方口径，也是我核对时反复确认过的：

- Go、Plus、Pro **只能按月付**，官方不支持年付或预付多个月。看到「年付立省」，先问清楚那是谁在垫钱、周期怎么算。
- **会员不含 API 额度**，一次都没有例外。
- 在哪买在哪退：官网订阅在 ChatGPT 设置里取消，App Store 订阅在 Apple 那边取消。卸载 App 不等于取消订阅。
- 各档位之间的用量差距，官方**没有**给出相对 Plus 的固定倍数；商家标的「5X / 10X / 25X」不是官方口径。
- 人民币实付因渠道而异（汇率、手续费、礼品卡溢价、平台标价都不同），**以付款当次的结算页为准**。

## 五、代充四步：我的实际操作

代充的核心就一句话：你用人民币付款，由平台为**你自己的** ChatGPT 账号开通或续费对应方案。正规交付一般只要临时会话凭据（Session），不需要密码。

以我后来固定的流程为例（各家平台步骤大同小异，逐步截图各家教程里都有）：

### 步骤 1：选档

先想清楚要 Go、Plus 还是 Pro，再到平台套餐页核对周期和当日价格。

我固定先做一件事：**截下自己账号的订阅页**，记下当前档位和到期日。账号里已经有订阅（官网 / Apple / Google Play）时，先问清平台怎么衔接，避免两份订阅同时计费 —— 这是我第一次续费时白付一个月换来的教训。

### 步骤 2：提交 Session

登录自己的 ChatGPT，按结算页说明复制临时 Session，粘贴回订单页。

- 全程不需要密码、验证码、恢复码。
- Session 在一段时间内可能等同于登录权限：只填在平台自己的 HTTPS 订单页，不要发到群聊、私聊，也不要截图外传。
- 开通完成后，去 ChatGPT 设置里「退出所有设备」，让这份 Session 尽快失效。

### 步骤 3：付款

用微信或支付宝在**平台生成的订单里**付款，保留订单号。不要按「客服私聊」的要求转账到个人账户。

我付完会立刻截一张：订单号 + 金额 + 时间。这三样在验收和售后时都用得上。

### 步骤 4：验收

用**同一个**账号登录官方 ChatGPT，到 **设置 → 账户** 核对两件事：

1. 方案名称（Go / Plus / Pro 及 Pro 档位）是否正确；
2. 有效期 / 下次扣费日是否合理。

**只认账号内显示，不凭「能聊天了」或订单状态单独判断。** 如果仍显示 Free，先确认是不是登错了号，尤其是用 Apple「隐藏邮件地址」登录的情况（来源：[What is ChatGPT Plus?](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus) 的 "Charged but still on Free plan" 一节）。

## 六、想买 Plus：这一节单独讲

搜「ChatGPT Plus 购买」的人，最需要的是一个默认答案，而不是十选一。我的默认答案是：**Plus**。

什么时候 Plus 就够：

- 每天写作、办公、学习、轻度编程，Free / Go 明显不够用；
- 需要进阶模型、Codex、深度研究，但还没到整天顶格跑；
- 一个人用，不需要多席位和团队后台。

什么时候才看 Pro：

- Plus 的用量**反复**卡住真正要交付的工作（不是偶发失败一次）；
- 长时间重度跑 Codex 或深度研究，用了 credits 补量之后仍然不够；
- 你已经连续记了两三周用量，能拿出「同一层窗口反复撞」的证据。

这里我要强调一个反直觉的点：**Plus 触限后可以先买 credits，不必先升档。** 升档是长期成本，credits 是一次性补量；把这两件事搞混，一年多花的钱足够再买几个月 Plus。

Codex 的用量细节和速度倍率，见本仓 [docs/codex.md](docs/codex.md) 与姊妹篇 [Codex 充值指南](https://github.com/cc-studi0/codex-daichong)。

## 七、我怎么算这笔账

我不比「哪个标价最低」，我比三样东西：

| 维度 | 我为什么在意 | 我的实际权重 |
| --- | --- | --- |
| 一次能办成的时间 | 拒付、切区、找客服都是时间 | 高 |
| 凭据风险 | 要密码的渠道直接出局 | 最高 |
| 续费可控性 | 会不会在我不知道的时候自动扣款 | 高 |
| 单月价格 | 重要，但排在上面三项之后 | 中 |

按这个权重，官网（有卡的话）最优，App 内购次之，代充第三 —— 但代充是唯一不需要外币卡就能办成的，所以它排第三不等于它差，而是**它的质量取决于你选哪一家**。

## 八、避坑清单

- 🚫 要密码、短信 / 邮箱验证码、2FA 恢复码的「代充」→ 立刻停，换渠道。
- 🚫 只收 Session，但没有订单号、没有进度页，全靠私聊口头承诺 → 谨慎。
- 🚫 要求转账到个人账户、绕过站内订单的「内部渠道」→ 不要付。
- 🚫 会员还在有效期内，又重复买**同档**订阅 → 可能两处同时计费。先关原渠道自动续费，再下单。
- 🚫 为了 API 余额去买会员 → 两套账单，互不抵扣。
- 🚫 把成品号 / 拼车当成「ChatGPT 充值」→ 账号不归你，也不是给自有账号开通。
- 🚫 价格明显离谱却承诺「必不封号」「官方一样」→ 当营销话术看，不要当保证。
- 🚫 去找「黑卡 / 白卡 / 某卡商出卡」这类操作；礼品卡失败时，换正规代充或换支付方式就行。
- ✅ 验收只在官方账号内做；售后时保留订单号和脱敏截图。

## 九、挑平台时我实际在看什么

付款前逐项过一遍，做不到多项就换一家。不必追求满分，**优先看凭据和订单这两项**。

**凭据安全**

1. 不要 ChatGPT 密码、邮箱密码、验证码、恢复码。
2. 提交凭据的入口是平台自己的 HTTPS 页面，而不是发到个人微信或来历不明的第三方表单。
3. 写明凭据用完后怎么处理，以及你自己怎样让 Session 失效。

**价格与交付**

4. 价格明码标出，并写清周期（1 个月 / 按官方账期）。
5. 写清交付物：给你**自己的账号**开会员，而不是给你一个新号。
6. 写清已有订阅时怎么衔接，不默认「会自动叠加」。
7. 不承诺官方都做不到的事（例如「锁定永久旧额度」「绝不封号」）。

**订单、售后与验收**

8. 有订单号和状态页，付款后能查进度。
9. 质保 / 退款规则写清楚，并写明哪些情况**不包括**（例如账号被封）。
10. 只在平台订单内付款；平台也会要求你回官方账号核对方案和到期日。

能开发票、页面好看、价格低，都不能单独证明靠谱。更有用的信号是：**要的凭据最少、规则写在页面上、出了问题能凭订单号找到人。**

## 十、附录：付款后最常见的 10 个问题，按这个顺序查

这一节写的是「钱付出去之后」的事。顺序很重要，因为很多人的第一反应是重复下单，而重复下单会让问题更难查。

### 1. 付款成功，账号还显示 Free

先别付第二次。按这个顺序查：① 是不是登错账号（尤其 Google / Apple / 邮箱密码登录会分成不同账号）；② 用 Apple「隐藏邮件地址」登录的，去核对 Apple 生成的中继邮箱；③ App 端试一次「恢复购买」；④ 退出所有设备再用购买时的身份登录。

### 2. 收到扣款短信，但订单页显示未支付

渠道扣款和平台订单状态不同步，常见于第三方支付中间层。带订单号找平台客服，让它按支付流水号核对；同时保留银行的扣款记录截图。

### 3. 提示「卡片被拒」，但卡里有钱

拒付多数不是余额问题。国内发卡在 Stripe 侧常被直接识别拒付；另外账单地址、3DS 验证、地区支持都会影响结果。**别连点重试**，连续失败会叠加风控。

### 4. 3D Secure 验证页跳不出来

允许结账页弹窗和重定向，停用可能拦截的扩展，换无痕窗口或另一网络再试；仍不出验证页，请发卡行确认该卡是否支持线上、跨境和周期性交易的 3DS。

### 5. 官网显示「该地区暂不支持」

聊天页能打开，不代表支付页会放行。官方[支持地区列表](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)是明确列出的，位于列表之外时不要用改地址、换区的方式硬绕。

### 6. 同时被扣了两次

先确认是不是「网页 + App Store」两份订阅同时存在：这是最常见的重复扣款原因。处理顺序是先在原渠道取消一份，再找实际收款方退多出来的那一笔，两边同时发起反而更慢。

### 7. 想取消，但找不到取消入口

官网订阅去 ChatGPT 设置里取消；App Store 订阅去 iPhone 设置 → 你的名字 → 订阅里取消。**卸载 App 不会取消订阅**，这是最高频的误解。

### 8. 续费日当天被降回 Free

先看账号页的到期日和续费状态，再看原付款渠道是否扣款成功。续费失败通常不会立刻降级，但如果渠道那边一直失败，到期后就会掉档。

### 9. 会员正常，API 却报余额不足

两套账单，正常。去开发者平台单独充值，不要通过买会员来「补 API」。

### 10. 账号被限制或停用

先分清是使用规则问题、地区问题，还是支付来源问题。能在官方渠道申诉就走官方；同时保留订单与沟通记录。不要用「再开一个新号继续用」的方式处理，历史记录和工作流都搬不过去。

## 十一、常见问题 FAQ

**Q1：ChatGPT 充值和 ChatGPT 代充有什么区别？**
在中文搜索里基本是同一个需求：用人民币（或借助第三方）给账号开通或续费会员。真正要区分的是**交付方式** —— 开在你自己的账号上，还是卖你一个别人的号。前者才是这篇说的充值 / 代充。

**Q2：Plus 购买和充值是一回事吗？**
对个人用户通常是：买 Plus 就是给账号开通 Plus 订阅，区别只在付款路径（官网、App Store、代充）。

**Q3：代充会不会封号？**
没有人能替官方保证不封号。能做的只有三件事：只选订单可查、不碰密码的渠道；遵守使用条款和支持地区规则；不给密码。凡是承诺「零风险 / 必不封号 / 官方认可」的，反而要警惕。

**Q4：会员里含 API 余额吗？**
不含。会员和 API 是两套独立计费，需要 API 就去开发者平台充值（来源：[What is ChatGPT Plus?](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)）。

**Q5：和「Codex 充值」是什么关系？**
Codex 的用量跟着 ChatGPT 方案走，所以很多「Codex 充值」需求，本质上还是给 ChatGPT 开 Plus / Pro，或者买 credits。详见 [Codex 充值指南](https://github.com/cc-studi0/codex-daichong)。

**Q6：付完钱怎么验收才算到账？**
登录同一个账号，看官方账户页的**方案名称和有效期**。能发消息、能看到某个模型，都不能单独证明已到账。App 端显示异常时，可以试「恢复购买」（仅适用于应用商店订阅）。

**Q7：已经是 Plus，还能再买一个月叠加吗？**
不要默认能叠加。官方不支持预付多个月。先查清当前订阅从哪里付、什么时候到期、有没有自动续费，再问清平台怎么衔接。

**Q8：官网能不能直接用微信 / 支付宝？**
官网可用支付方式因国家而异（来源：[What is ChatGPT Go?](https://help.openai.com/en/articles/11989085-what-is-chatgpt-go) 里关于 Multi-currency billing 的说明）。中国大陆不在官方支持地区内，国内用户一般无法直接用微信 / 支付宝在官网订阅；没有海外支付方式时，常见选择是外区 App Store 或人民币代充。

**Q9：想省事，最省事的做法是什么？**
先把账号、订阅来源、到期日写在一条备忘录里，再决定从哪买。省事的关键不是「哪家最快」，而是**你清楚自己现在有什么、下次什么时候到期**。这一点做到了，三条路径都不会踩坑。
